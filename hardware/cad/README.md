# Tokimi Rover CAD

The owner-approved **Supercar V3** top-cover design is published in
[top-cover-v3](top-cover-v3/README.md), including procedural Blender source, a
self-contained editable BLEND, 3MF/STL/OBJ exports, an A4 1:1 mounting template,
previews, validation evidence, checksums, and rebuild instructions.

The published design uses **195 × 100 mm** M3 hole-center spacing. The earlier
physical record in [HARDWARE_AS_BUILT.md](../../HARDWARE_AS_BUILT.md) says
approximately **203 × 105 mm** for a historically printed cover. This audit did
not establish that the earlier cover and published V3 are the same object, nor
did it fit V3 to the rover. Measure the chassis and use the calibrated paper
template before printing or drilling.

No final parametric STEP/FCStd/Fusion model or GLB is supplied. The canonical
editable source is the procedural Blender Python chain; the BLEND and mesh
files are generated/editable outputs.
