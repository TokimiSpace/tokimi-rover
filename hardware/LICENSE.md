# Hardware licensing

Tokimi Rover uses separate licenses for hardware source and explanatory
documentation:

| Path or material | License |
|---|---|
| `bom/BOM.md` | CERN-OHL-W-2.0 |
| Future actual CAD, schematic, PCB, fabrication, and manufacturing source under `cad/` | CERN-OHL-W-2.0 |
| `README.md` and the current `cad/README.md` status document | CC-BY-4.0 |
| `wiring/tokimi-rover-wiring.svg` and its PNG export | CC-BY-4.0 |

The complete texts are
[CERN-OHL-W-2.0](../LICENSES/CERN-OHL-W-2.0.txt) and
[CC-BY-4.0](../LICENSES/CC-BY-4.0.txt). V0.1 contains no editable CAD model;
the hardware license does not make absent design files available.

The CERN-OHL-W-2.0 Source Location for currently published Covered Source is
[`https://github.com/TokimiSpace/tokimi-rover/tree/main/hardware`](https://github.com/TokimiSpace/tokimi-rover/tree/main/hardware).
A tagged release should use a tag-specific Source Location in its release
manifest.
