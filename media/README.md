# Media

Only publish media that has been reviewed for privacy, location data, personal
network details, visible credentials, third-party rights, and safe operating
practice. Keep unreviewed material under `media/private/`; that directory is
ignored by Git.

The repository includes a CC-BY-4.0 conceptual hero illustration. It is not a
product photograph and must not be presented as physical test evidence. The
V0.1 release still needs cleared wiring photographs and a short
field-demonstration video that does not imply autonomy or production
reliability.
